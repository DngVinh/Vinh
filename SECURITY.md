# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities directly to the maintainers via email or private channels. Do not open public issues for security vulnerabilities. We will triage and fix the vulnerability within 48 hours.
