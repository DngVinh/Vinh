# Contributing to Campus 24/7

First off, thank you for considering contributing to Campus 24/7. It's people like you that make this tool such a great community.

## Where do I go from here?
If you've noticed a bug or have a feature request, make sure to check our [Issues](../../issues) to see if someone else in the community has already created a ticket. If not, go ahead and [make one](../../issues/new/choose)!

## Fork & create a branch
If this is something you think you can fix, then fork Campus 24/7 and create a branch with a descriptive name.

## Get the test suite running
Make sure you can build and run tests locally. Follow the instructions in the README to set up your environment.

## Implement your fix or feature
At this point, you're ready to make your changes! Feel free to ask for help; everyone is a beginner at first.

## Make a Pull Request
At this point, you should switch back to your master branch and make sure it's up to date with Campus 24/7's master branch.
Then, create a PR.

## Code Review
Once your PR is open, it will be reviewed. We may ask you to make some changes.
